# LibanApps Local — النسخة المحلية (Offline)

برنامج بينزل على كمبيوتر الزبون، والبيانات كلها بتنحفظ **على الكمبيوتر نفسه**.
بيشتغل بلا إنترنت، وإذا بدك تفوت من برّا (تلفون، بيت) بتفوت عبر رابط آمن والبيانات بتضل عالكمبيوتر.

البرامج المشمولة هلق: **محاسبة الألمنيوم** و **محاسبة التجارة**.
(المنيو والمتجر والنادي والتوصيل بيضلّو أونلاين متل ما هني — الزباين بيطلبوا من الإنترنت.)

---

## كيف بيشتغل

```
كمبيوتر المحل
 ├─ LibanApps.exe  ← نافذة البرنامج + أيقونة بجنب الساعة
 ├─ سيرفر محلي     ← http://127.0.0.1:47801
 ├─ قاعدة بيانات   ← %APPDATA%\LibanApps\data\libanapps.db  (SQLite)
 ├─ نسخ احتياطية  ← Documents\LibanApps Backups  (+ نسخة مشفّرة عالسحابة اختياري)
 └─ cloudflared    ← نفق آمن لـ shop1.libanapps.com  (اختياري)

libanapps.com (السحابة) ← بس للتأكد من الاشتراك + النسخ المشفّرة
```

- صفحات البرنامجين **نفسها** يلي عالموقع (`public/app-alum.html` و `app-trade.html`) — ما في نسخة تانية لازم تصونها.
  السيرفر المحلي بيبدّل مكتبة Supabase بملف `web/supabase-local.js` يلي بيبعت كل شي لقاعدة البيانات المحلية.
- قواعد «الوضع الآمن» نفسها منفّذة محلياً: ما في قراءة قبل الدخول، كلمات السر مشفّرة (scrypt)، 2FA، صلاحيات المستخدم المخصّص، الزبون بيشوف حسابه بس، والعامل يومياته بس، وقفل بعد ٨ محاولات غلط.
- لايف بين الأجهزة: إذا في كذا حدا فايت (من الكمبيوتر ومن التلفون عبر الرابط)، التعديلات بتوصل للكل بلا refresh.

## الترخيص

- صاحب المحل بيسجّل دخول مرة وحدة بحساب libanapps.com (من تبويب **التفعيل**).
- البرنامج بيتأكد من الاشتراك (`app_access`) كل ٦ ساعات إذا في إنترنت.
- بلا إنترنت بيكمّل **١٠ أيام** من آخر تأكيد، بعدها بيطلب اتصال.
- أو رقم تفعيل `HMDH1...` (نفس أرقامك) — بيشتغل بلا إنترنت أبداً لحد تاريخ الانتهاء.
- التجديد والإيقاف من `/super` متل العادة — بيوصل للكمبيوتر بأول تحقق.

## البناء (على كمبيوتر ويندوز، مرة وحدة)

بدك **Node.js 22** أو أحدث.

```bat
cd offline
npm install
npm run build
```

بيطلع المثبّت بـ `offline\dist\LibanApps-Local-Setup-2.0.0.exe` — هيدا يلي بتعطيه للزبون.

`npm run build` بيعمل تلقائياً:
1. بينسخ `public/app-alum.html` و `app-trade.html` و `assets/` (يعني كل ما تعدّل البرنامج أونلاين، بتعمل build جديد وبيطلع معو التعديل)
2. بينزّل مكتبة QR والخطوط (Cairo / Tajawal) لتشتغل بلا إنترنت
3. بينزّل `cloudflared.exe`

للتجربة بلا بناء: `npm start` (بيفتح البرنامج بـ Electron)، أو `npm run server` وافتح `http://127.0.0.1:47801`.

## مرة وحدة على Supabase

شغّل `db/upgrade-local-backups.sql` بالـ SQL Editor — بيعمل bucket خاص `local-backups` للنسخ المشفّرة (كل مؤسسة بمجلدها بس).

## تركيب عند زبون جديد

1. نزّل `LibanApps-Local-Setup.exe` وثبّتو.
2. بيفتح على صفحة **التفعيل** → سجّل دخول بحساب الزبون على libanapps.com.
3. **المستخدمين** → اعمل أول مدير (اسم + كلمة سر) للبرنامج.
4. **النسخ الاحتياطي** → حط كلمة سر للنسخ (واكتبها للزبون على ورقة) وفعّل «ارفع عالسحابة».
5. افتح البرنامج من الصفحة الرئيسية.

### زبون كان شغّال أونلاين؟
تبويب **نقل من السحابة** → اختار البرنامج، وادخل بمستخدم **مدير** → بيسحب كل الجداول (زباين، فواتير، مخزن، صندوق، ورديات...).
كلمات سر باقي المستخدمين مشفّرة بالسحابة وما بتنقل — عيّنها من **المستخدمين**.

## الوصول من برّا (Cloudflare Tunnel)

لكل زبون بتعمل نفق مرة وحدة من حسابك بـ Cloudflare:

1. Cloudflare → **Zero Trust → Networks → Tunnels → Create a tunnel** → اختار **Cloudflared** → الاسم مثلاً `shop1`.
2. بصفحة التركيب، انسخ الأمر يلي بيطلع (فيه رمز طويل بيبلّش بـ `eyJ`). ما تشغّلو — البرنامج بيشغّلو.
3. **Public Hostname**: Subdomain = `shop1` · Domain = `libanapps.com` · Service = `HTTP` · URL = `127.0.0.1:47801`
4. عند الزبون: **الوصول من برّا** → النوع «رابط ثابت» → الرابط `shop1.libanapps.com` → الصق الأمر/الرمز → **تشغيل**.

بعدها الزبون بيفوت من أي مكان على `https://shop1.libanapps.com/trade`.

ملاحظات:
- الكمبيوتر لازم يكون شغّال ومتصل. البرنامج بيشتغل مع ويندوز تلقائياً وبيضل بجنب الساعة لما تسكّر النافذة.
- إعدادات التفعيل والنسخ والمستخدمين **ما بتنفتح من الرابط** — من الكمبيوتر نفسه بس.
- إذا الـ Worker عندك على `*.libanapps.com/*`، خلّيه `libanapps.com/*` بس، وإلا بياخد طلبات `shop1` قبل النفق.
- «رابط مؤقت» = رابط `trycloudflare.com` بلا حساب، بيتغيّر كل مرة — للتجربة بس.

## التحديث — تلقائي بالكامل

### إذا عدّلت برنامج الألمنيوم أو التجارة (الصفحات)
بتعدّل وبترفع على GitHub متل العادة — **وخلص**.
- الموقع بيحسب بصمة الصفحات المنشورة على `libanapps.com/api/offline/manifest`.
- برنامج الزبون بيفحص كل ساعة، بينزّل بس يلي تغيّر، بيتأكد من البصمة، وبيبدّل لحالو.
- الصفحات المفتوحة (عالكمبيوتر أو عالتلفون) بتتحدّث لحالها إذا ما حدا عم يستعملها، وإلا بيطلع شريط «نزلت نسخة جديدة» مع زر.
- البيانات ما بتتأثر، وفي زر **رجوع للنسخة السابقة** بتبويب **التحديث** إذا لزم.

### إذا عدّلت البرنامج نفسو (مجلد offline: السيرفر، الإعدادات...)
1. كبّر الرقم بـ `offline/package.json` (مثلاً `2.1.0`) ← `npm run build`.
2. ارفع ملف `dist\LibanApps-Local-Setup-2.1.0.exe` على مكان عام (مثلاً Supabase Storage bucket عام أو R2) وخود الرابط.
3. ```
   node offline/scripts/publish-update.js --installer offline\dist\LibanApps-Local-Setup-2.1.0.exe --url https://...exe
   ```
   ← ارفع على GitHub.
4. عند الزبون: بينزل لحالو بالخلفية، وبيتركّب صامت (بلا أسئلة) بالليل بين ٢ و٥ الصبح أو بأول ما يفتح البرنامج، وبيرجع يفتح لحالو.

إذا الصفحات الجديدة بدها نسخة أحدث من البرنامج نفسو: `--min-local 2.1.0`، فالزباين يلي عندهن نسخة أقدم ما بياخدو تحديث الصفحات قبل ما ينزّلو البرنامج الجديد.

## النسخ الاحتياطي والاسترجاع

- نسخة كاملة كل ٢٤ ساعة (بتتغيّر) + عند إغلاق البرنامج إذا آخر نسخة أقدم من ٦ ساعات.
- مضغوطة ومشفّرة AES-256-GCM بكلمة سر النسخ. **بلا كلمة السر ما في حدا بيقدر يفتحها، ولا أنت.**
- آخر ٣٠ نسخة عالكمبيوتر، وآخر ١٤ عالسحابة.
- كمبيوتر خرب؟ ثبّت البرنامج عالجديد → فعّل بنفس الحساب → **النسخ الاحتياطي → نسخ السحابة** → استرجاع.

## الملفات

| الملف | شو بيعمل |
|---|---|
| `main.js` / `preload.js` | برنامج ويندوز (Electron): نافذة، أيقونة الساعة، طباعة صامتة |
| `server/index.js` | السيرفر المحلي والمسارات |
| `server/data.js` | محرّك البيانات + الدخول + الصلاحيات (نسخة محلية من `secure-apps.sql`) |
| `server/store.js` | SQLite |
| `server/license.js` | التحقق من الاشتراك + أرقام HMDH1 |
| `server/backup.js` | النسخ المشفّرة والاسترجاع |
| `server/tunnel.js` | تشغيل cloudflared ومراقبته |
| `server/cloud-import.js` | نقل البيانات من السحابة |
| `web/supabase-local.js` | بديل supabase-js بالمتصفح |
| `web/home.html` | الصفحة الرئيسية والإعدادات |
| `scripts/prepare.js` | تجهيز الملفات قبل البناء |

## شو مش متوفّر بالنسخة المحلية
- الدخول بكود واتساب (بيدخلو باسم المستخدم وكلمة السر).
- فتح مؤسسة الزبون من `/super` (البيانات عالكمبيوتر تبعو، مش بالسحابة).
- استيراد صور المنتجات من الإنترنت بيحتاج إنترنت (بيمرق عبر libanapps.com).
