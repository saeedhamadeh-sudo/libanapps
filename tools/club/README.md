# برنامج إدارة النوادي (club)

## التركيب — مرة واحدة
1. Supabase → SQL Editor → الصق كل `db/upgrade-club.sql` → Run (آمن للتشغيل أكثر من مرة).
   - بينشئ مخزن الصور `club` تلقائيًا. إذا ظهر تنبيه `bucket skipped`: Storage → New bucket → `club` (Public) وأعد تشغيل الملف.
2. ارفع التعديلات على GitHub (main) — Cloudflare بينشر لحاله. جرّب بنافذة Incognito.

## الروابط
| الصفحة | الرابط |
|---|---|
| لوحة المدير | `libanapps.com/portal-club/<slug>/admin` |
| صفحة التلاميذ | `libanapps.com/portal-club/<slug>` |
| شاشة الباب | `libanapps.com/portal-club/<slug>/door` (تنربط من اللوحة ← الباب) |

## الأسعار والتفعيل
- `/super` ← الباقات ← «برنامج النوادي — إعدادات التفعيل»: السعر أول سنة (500$)، التجديد (200$)، التجربة (7 أيام).
- `/super` ← إصدار ترخيص جديد ← «إدارة النوادي» + رابط النادي.
- الزبون يبدأ التجربة أو يشتري من صفحة حسابه. أول دفعة بعد التجربة بسعر السنة الأولى، وبعدها التجديد.

## تعديل الصفحات
الصفحات الثلاث `public/club-admin.html` و`club.html` و`club-door.html` **مولّدة**.
عدّل الملفات بـ `tools/club/src/` ثم شغّل:
```
node tools/club/build.js
```
الكود المشترك (البطاقة CR80، PDF، QR، التعرّف على الوجه، الترجمة) موجود بـ `src/common.js`.

## فتح الباب
شاشة الباب ترسل طلبًا إلى «رابط فتح الباب» (من اللوحة ← الباب) عند السماح بالدخول — مناسب لريليه Shelly / ESP32 / Tasmota.
- Shelly Cloud (HTTPS) يعمل مباشرة.
- جهاز على الشبكة المحلية (http://192.168.x.x): في Chrome على جهاز الباب ← إعدادات الموقع libanapps.com ← «المحتوى غير الآمن» = سماح.
