# LibanApps للكمبيوتر (Windows)

بيفتح libanapps.com وبيضيف:
- لائحة طابعات الكمبيوتر بإعدادات POS (تختار الطابعة مرة وحدة على كل جهاز)
- طباعة الفاتورة لحالها بعد القبض — بلا نافذة طباعة
- ربط طابعة USB (WebUSB) لفتح الدرج

## البناء
```
cd desktop
npm install
npm run build
```
الملفات بتطلع بـ `desktop/dist/`: مثبّت (Setup) ونسخة محمولة (Portable).
